# সুরভি — Firebase-চালিত ল্যান্ডিং পেজ + চেকআউট + অ্যাডমিন

প্লেইন HTML/CSS/JS দিয়ে বানানো একটা সিঙ্গেল-প্রোডাক্ট COD (Cash on Delivery)
সেলস ফানেল: **ল্যান্ডিং পেজ → চেকআউট → থ্যাংক ইউ পেজ**, সাথে একটা
**অ্যাডমিন প্যানেল** যেখান থেকে অর্ডার দেখা যায় আর তিনটা পাবলিক পেজেরই
লেখা/দাম/ছবি এডিট করা যায় — কোনো কোড টাচ না করেই।

ব্যাকএন্ড হিসেবে **Firebase** (Firestore Database + Authentication)
ব্যবহার করা হয়েছে, আর **Facebook Pixel** বেস সেটআপ করা আছে
(PageView, ViewContent, InitiateCheckout, Purchase ইভেন্টসহ)।

> ডেমো কনটেন্ট হিসেবে একটা attar/আতর ব্র্যান্ড ("সুরভি উদ") বসানো
> হয়েছে — নাম, দাম, ছবি, রিভিউ সব জায়গা থেকে বদলে আপনার নিজের প্রোডাক্ট
> বসিয়ে নিতে পারবেন (নিচে "কনটেন্ট এডিট করা" অংশ দেখুন)।

## ফাইল স্ট্রাকচার

```
index.html       → ল্যান্ডিং পেজ
checkout.html     → চেকআউট পেজ
thankyou.html      → থ্যাংক ইউ / অর্ডার কনফার্মেশন পেজ
admin.html         → অ্যাডমিন প্যানেল (লগইন সুরক্ষিত)
style.css          → সব পেজের ডিজাইন
config.js           → *** এই ফাইলে আপনার Firebase + Pixel তথ্য বসাবেন ***
pixel.js            → Facebook Pixel লোডার
main.js / checkout.js / thankyou.js / admin.js → প্রতিটা পেজের লজিক
firestore.rules      → Firestore সিকিউরিটি রুলস
firebase.json         → Firebase Hosting দিয়ে ডিপ্লয় করতে চাইলে দরকার
```

সব ফাইল একই ফোল্ডারে (flat) রাখবেন — কোনো সাব-ফোল্ডারে ঢোকাবেন না,
নাহলে `href="style.css"` এর মতো রিলেটিভ পাথগুলো ভেঙে যাবে।

---

## ধাপ ১ — Firebase প্রজেক্ট বানানো

1. https://console.firebase.google.com এ যান, Google একাউন্ট দিয়ে লগইন করুন।
2. **Add project** এ ক্লিক করুন, একটা নাম দিন (যেমন `surovi-shop`), বাকি
   ধাপগুলো ডিফল্ট রেখে **Create project** ক্লিক করুন।

## ধাপ ২ — Firestore Database চালু করা

1. বাম পাশের মেনু থেকে **Build > Firestore Database** এ যান।
2. **Create database** ক্লিক করুন।
3. **Production mode** সিলেক্ট করুন (আমরা নিজেদের rules বসাব, তাই এটা
   ম্যাটার করে না) এবং কাছের একটা location (যেমন `asia-south1`) বেছে
   নিন।

## ধাপ ৩ — Authentication চালু করা + অ্যাডমিন ইউজার বানানো

1. **Build > Authentication** এ যান, **Get started** ক্লিক করুন।
2. **Sign-in method** ট্যাবে গিয়ে **Email/Password** চালু (enable) করুন।
3. **Users** ট্যাবে গিয়ে **Add user** এ ক্লিক করে নিজের অ্যাডমিন
   ইমেইল + পাসওয়ার্ড দিয়ে একটা ইউজার বানান।
   এই ইমেইল/পাসওয়ার্ড দিয়েই `admin.html` এ লগইন করবেন।

   > সাইটে কোনো পাবলিক "Sign up" ফর্ম রাখা হয়নি ইচ্ছাকৃতভাবে —
   > শুধু আপনি Console থেকে যাদের একাউন্ট বানাবেন তারাই অ্যাডমিনে
   > ঢুকতে পারবে।

## ধাপ ৪ — `config.js` এ আপনার তথ্য বসানো

1. Firebase Console এ প্রজেক্টের ভিতরে, বাম পাশে গিয়ার আইকন থেকে
   **Project settings** এ যান।
2. নিচের দিকে **Your apps** সেকশনে **Web** আইকন (`</>`) ক্লিক করে একটা
   ওয়েব অ্যাপ রেজিস্টার করুন (একটা নিকনেম দিন, Firebase Hosting সেটআপের
   দরকার নেই এই ধাপে)।
3. যে `firebaseConfig` অবজেক্টটা দেখাবে সেটা কপি করে `config.js`
   ফাইলে বসিয়ে দিন (উপরের অংশে, `YOUR_API_KEY` ইত্যাদি বদলে দিন)।

## ধাপ ৫ — Firestore Security Rules বসানো

1. Firestore Database > **Rules** ট্যাবে যান।
2. এই প্রজেক্টের `firestore.rules` ফাইলের পুরো কনটেন্ট কপি করে
   Console এর এডিটরে পেস্ট করুন, তারপর **Publish** করুন।

এই rules ছাড়া সাইট কাজ করবে না — ডিফল্টভাবে Firestore সব এক্সেস
বন্ধ রাখে।

## ধাপ ৬ — Facebook Pixel ID বসানো

1. Meta Events Manager (business.facebook.com/events_manager) এ যান।
2. আপনার Pixel সিলেক্ট করুন (না থাকলে নতুন Pixel বানান) → **Settings**
   এ Pixel ID পাবেন (একটা সংখ্যা, যেমন `123456789012345`)।
3. `config.js` ফাইলে `FB_PIXEL_ID` এর জায়গায় এই সংখ্যাটা বসান।

ইভেন্টগুলো এমনিতেই বসানো আছে:
- **PageView** — সব পাবলিক পেজে (pixel.js)
- **ViewContent** — ল্যান্ডিং পেজে (main.js)
- **InitiateCheckout** — চেকআউট পেজ লোড হলে (checkout.js)
- **Purchase** — থ্যাংক ইউ পেজে, অর্ডারের টাকার পরিমাণসহ (thankyou.js)

Meta Events Manager এর **Test Events** ট্যাব দিয়ে এগুলো লাইভ চেক
করতে পারবেন।

## ধাপ ৭ — লোকালি চালিয়ে দেখা

`config.js` আর `FB_PIXEL_ID` বসানোর পর, একটা সিম্পল লোকাল সার্ভার দিয়ে
চালান (সরাসরি ফাইলে ডাবল-ক্লিক করলেও প্রায়ই কাজ করে, কিন্তু সার্ভার
দিয়ে চালানো বেশি নিরাপদ):

```bash
# পাইথন থাকলে
python3 -m http.server 8000

# অথবা Node থাকলে
npx serve .
```

তারপর ব্রাউজারে `http://localhost:8000` খুলুন।

## ধাপ ৮ — লাইভ করা (Deploy)

**অপশন ১ — Firebase Hosting (রেকমেন্ডেড, ফ্রি):**
```bash
npm install -g firebase-tools
firebase login
firebase deploy
```
(এই ফোল্ডারেই `firebase.json` আগে থেকে বসানো আছে, তাই `firebase init`
আবার করার দরকার নেই — শুধু `firebase use --add` দিয়ে আপনার প্রজেক্ট
সিলেক্ট করে নিন প্রথমবার।)

**অপশন ২ —** যেকোনো স্ট্যাটিক হোস্টিং (Netlify, Vercel, GitHub Pages
ইত্যাদি) — যেহেতু এটা প্লেইন HTML/CSS/JS, শুধু ফোল্ডারটা আপলোড করলেই
চলবে।

## কনটেন্ট এডিট করা (Admin থেকে)

`admin.html` এ লগইন করে **কন্টেন্ট এডিট** ট্যাবে যান। উপরে তিনটা বাটন
(ল্যান্ডিং / চেকআউট / থ্যাংক ইউ) দিয়ে পেজ বেছে নিয়ে যেকোনো ফিল্ড বদলে
**সেভ করুন** চাপলেই সাথে সাথে লাইভ সাইটে পরিবর্তন দেখা যাবে (পেজ
রিফ্রেশ করলে)।

এভাবে যা যা বদলানো যায়: হেডলাইন, প্রোডাক্টের নাম/দাম, ছবির URL, ফিচার
কার্ড, প্রোডাক্ট বিবরণ, গ্যালারি, রিভিউ, FAQ, ডেলিভারি চার্জ,
থ্যাংক-ইউ মেসেজ — সবকিছু।

ছবির জন্য: যেকোনো ইমেজ হোস্টিং (Firebase Storage, imgbb.com, বা অন্য
কোনো CDN) এ ছবি আপলোড করে সরাসরি লিংক (URL) বসিয়ে দিন।

## অর্ডার দেখা (Admin থেকে)

**অর্ডারসমূহ** ট্যাবে সব অর্ডার রিয়েল-টাইমে দেখা যায় (নতুন অর্ডার
এলে পেজ রিফ্রেশ না করেই দেখা যাবে)। নাম/ফোন দিয়ে সার্চ করা যায়,
স্ট্যাটাস দিয়ে ফিল্টার করা যায়, আর প্রতিটা অর্ডারের স্ট্যাটাস
(অপেক্ষমান → কনফার্মড → শিপড → ডেলিভার্ড / বাতিল) ড্রপডাউন থেকে
বদলানো যায়।

## সীমাবদ্ধতা ও ভবিষ্যতে যা যোগ করা যায়

- এটা সম্পূর্ণ ক্লায়েন্ট-সাইড (কোনো নিজস্ব ব্যাকএন্ড সার্ভার নেই),
  তাই থিওরিটিক্যালি কেউ Firebase config দেখে সরাসরি Firestore এ ভুয়া
  অর্ডার পাঠানোর চেষ্টা করতে পারে। বড় স্কেলে গেলে
  [Firebase App Check](https://firebase.google.com/docs/app-check)
  চালু করার পরামর্শ থাকবে — এটা স্প্যাম/বট ঠেকাতে সাহায্য করে।
- এখানে "লগইন করা মানেই অ্যাডমিন" — একজনের বেশি অ্যাডমিন লেভেল (যেমন
  শুধু অর্ডার দেখতে পারবে, কনটেন্ট এডিট করতে পারবে না) দরকার হলে
  Firebase Custom Claims + Cloud Functions লাগবে।
- এখন একটাই প্রোডাক্ট সাপোর্ট করে। একাধিক প্রোডাক্ট / কার্ট সিস্টেম
  দরকার হলে সেটা একটা বড় এক্সটেনশন — আলাদাভাবে জিজ্ঞেস করলে সেটাও
  বানিয়ে দেওয়া যাবে।
- রিভিউ আর FAQ সংখ্যায় ফিক্সড (৩টা রিভিউ, ৪টা FAQ) — অ্যাডমিন থেকে
  নতুন আইটেম যোগ/বাদ দেওয়ার UI নেই, শুধু বিদ্যমানগুলো এডিট করা যায়।
